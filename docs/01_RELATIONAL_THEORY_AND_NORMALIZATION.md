# Relational Database Theory & Normalization

## Normalization Forms Breakdown
- **1NF (First Normal Form)**: Atomic values, no repeating groups.
- **2NF (Second Normal Form)**: 1NF + no partial dependency on composite primary keys.
- **3NF (Third Normal Form)**: 2NF + no transitive dependencies (non-key attributes depend only on the primary key).
- **BCNF (Boyce-Codd Normal Form)**: Every determinant is a candidate key.
